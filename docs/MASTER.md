# EveryWay master (concise)

Wave 0.2 is the contract implementers use. The six repository names stay. EveryWay is the only UI. Atlas owns world facts. Enigma owns deterministic routing. Conduit owns transport and `contracts/`. Beacon observes. Harbor is outside this loop.

The core loop must not require an LLM, a cloud database, a payout, or a sponsor API. Missing evidence is not clearance. `routingCost` is not ETA.

Package version `wave0.2`. Wire `schemaVersion` `"1.0"`. Graph `seaside-market-v1`. Demo session alias `demo-main`.
